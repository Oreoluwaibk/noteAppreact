# Note app

A small React notes app, in the style of the Keeper tutorial. You type a note, add it to the list, and delete it. The screen is `Header`, `CreateArea`, `Note`, and `Footer` in `src/components`.

It was started on CodeSandbox. The package name is `keeper-part-3-add-click-and-delete-function`.

## Stack

Create React App and React.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). `npm run build` writes the production bundle to `build/`.
